# 相簿（離線私人相簿 PWA）

純前端、無後端、可離線使用的 iPhone 相簿。相片與影片只存在你手機本機（IndexedDB），不會上傳到任何地方。

## 功能
- 導入相片與影片（從 iPhone 相簿選取，可一次多選）
- 影片以第一幀作封面，顯示時長
- 按日期分組的網格、雙指縮放、雙擊放大、拖動、左右滑動切換、下滑關閉
- 多選（長按或按「選取」）：匯出、收藏、加入相簿、刪除
- 自建相簿、收藏、影片智慧相簿
- 九點手勢密碼（離開 App 即鎖定，連錯 5 次暫時鎖住）
- 匯出到系統相簿：透過分享選單「儲存影像／儲存影片」
- 深色模式（跟隨系統，也可在設定中手動切換）
- 完全離線（Service Worker）

## 部署到 GitHub Pages
1. 在 GitHub 新建一個**公開**倉庫（例如 `photo-vault`）。
2. 把本資料夾內所有檔案（含隱藏檔 `.nojekyll`）上傳到倉庫根目錄。
3. 倉庫 → Settings → Pages → Source 選 `Deploy from a branch`，Branch 選 `main`、資料夾 `/ (root)`，儲存。
4. 約一分鐘後，網址為 `https://你的用戶名.github.io/倉庫名/`。

> 倉庫公開只代表「程式碼」公開；你的相片只在手機本機，不會出現在 GitHub。

## 加到 iPhone 主畫面
1. 用 **Safari** 打開上面的網址（需要先連網一次）。
2. 點底部「分享」→「加入主畫面」。
3. **之後一律從主畫面圖示開啟**，並在那裡設定手勢密碼、導入相片。

> Safari 分頁和主畫面 App 的儲存空間是分開的：在 Safari 分頁裡導入的內容，不會出現在主畫面 App。請先加入主畫面，再導入。

## 需要知道的事
- **忘記手勢密碼無法找回**，只能在鎖定畫面選「忘記手勢密碼」→ 清除全部資料重設。
- 手勢密碼是介面鎖，不是加密。
- 刪除是永久刪除（沒有「最近刪除」）。
- 相片日期取自檔案的修改時間；iOS 有時會給導入時間而非拍攝時間。
- 網站無法直接讀寫系統相簿：導入靠選取檔案，匯出靠分享選單。
- 定期用「匯出」備份重要內容。清除 Safari 網站資料、或刪除主畫面 App 會一併刪除相片。
- 更新程式後，請把 `sw.js` 裡的 `CACHE` 版本號 +1，手機才會取得新版。
